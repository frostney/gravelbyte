# Search/discovery checks

The page keeps its minimal visible layout. The HTML supplies a descriptive
<title>, description, canonical URL, language, viewport, Open Graph title/URL/
description and a summary social card. A screen-reader heading identifies the
game; keyboard/installation instructions and real links are present without
JavaScript. A noscript message points users to the PicoSystem download.

The canonical URL is https://frostney.github.io/gravelbyte/ and sitemap.xml lists
that same URL. This project cannot control frostney.github.io/robots.txt; robots
rules are origin-level. The origin currently allows crawling. Do not put a
misleading project-subdirectory robots.txt in the repository.

Google Search Console ownership/index coverage has not been inspected. The owner
can submit the sitemap and inspect the canonical URL there. No ranking, indexing
or AI-search inclusion is promised. No invented review ratings, hidden keyword
copy or unsupported rich-result claims were added.
